# state-challenge
Tom Sissons submission for the State Product Challenge

This is a prototype to demo the intended UX of his proposed solution that fine-tunes an LLM on data ingested by the State system (e.g. social media posts, online petitions or conversations on online community groups).

All the code was generated in a 30-min session with Cursor Agent. You can view the transcript in this repository.

You can access the demo at: https://tomsissons.github.io/state-challenge/
